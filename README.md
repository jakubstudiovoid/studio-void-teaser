# STUDIO VOID

Prémiový teaser webu grafického studia **STUDIO VOID**. Portfolio v rekonstrukci.

Černá plocha, grotesk nápis, dlouhý reveal a spektrální loading bar.

## Obsah

- Reveal: číslo 000–100, rainbow bar, pak **STUDIO VOID** a *portfolio v rekonstrukci*
- Odkazy: [Instagram](https://instagram.com/studiovoid.cz), [Facebook](https://facebook.com/grafickestudiovoid)
- Přeskočit: klik, Escape, nebo tlačítko vpravo nahoře
- `/soukromi` — žádné cookies, žádná analytika

## Vercel

1. V [Vercel](https://vercel.com) → **Add New…** → **Project**
2. Import repozitáře `jakubstudiovoid/studio-void-teaser`
3. Framework: Vite (preset se vezme z `vite.config.ts` / Nitro)
4. Deploy. Doménu `studiovoid.cz` připojíte v Project → Settings → Domains.

Build command: `npm run build`  
Output: Nitro Vercel preset (nastavené v projektu)

## Lokálně

```bash
npm install
npm run dev
```
